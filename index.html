PersonalDriveArchive

A personal desktop utility for backing up and archiving the account owner's files to their Google Drive.

What the application does

  • Creates encrypted backups of selected personal notes and application data using restic.
  • Copies selected completed files to Google Drive in their original format using rclone. These ordinary archive files are not additionally encrypted by this utility.
  • Checks storage capacity and verifies transfers and backup restoration.

Google Drive access

The application requests the drive.file scope. This limits access to files created by the application or explicitly made available to it. Authorization happens through Google's sign-in page.

The application runs on the owner's computer. This website is informational and has no sign-in, upload form, or application backend. The utility is intended for personal use, with no public registration.
